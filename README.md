# Tayib data

Offline pack of the [Tayib](https://github.com/ams187) app: the 100,000 most-scanned food products sold in France, without photos.

- Built every week from the [Open Food Facts](https://world.openfoodfacts.org) data dump by `scripts/build-offline-pack.py`.
- Download: https://github.com/ams187/tayib-data/releases/latest/download/offline-pack.db
